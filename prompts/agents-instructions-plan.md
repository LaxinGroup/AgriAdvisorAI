# Plan: project-wide agent instructions

## Goal

Create a root `AGENTS.md` with project-wide guidance for the multilingual workplace assistant. The instructions will cover all stakeholders, content curators, and support staff and align with the three flows shown in the Figma PDF (`Downloads/Untitled.pdf`): a cited IT answer, bonus-policy guidance plus a human route, and escalation of an unanswered relocation-allowance question.

## Proposed instruction content

- Answer only from the approved knowledge base; do not guess or present unsupported claims.
- Detect the user's primary language and respond in that language, preserving any required output schema and routing tokens.
- Cite the relevant knowledge-base source and page or section for direct answers and partial information.
- For eligibility questions, explain only documented policy criteria, state that AI cannot determine individual eligibility, and route the user to a human specialist.
- For uncertain, incomplete, or out-of-scope questions, state what is known, do not invent a workaround, and hand off with a concise context summary.
- Use concise, professional language and the appropriate IT, Benefits, or Specialist category.
- Before making any project change, describe the intended files and edits and wait for the user's explicit approval. Do not edit additional files or expand scope without approval.

## Approval and implementation

This plan file is created with the user's approval. Before writing the root `AGENTS.md`, present its proposed contents and request separate explicit approval. Treat the guidance as behavioral; it does not technically enforce editor-level approval.

## Validation

After approval and creation, verify the root file exists, review it for completeness and consistency with the Figma flows, and confirm the nested `mobile/AGENTS.md` remains unchanged.
